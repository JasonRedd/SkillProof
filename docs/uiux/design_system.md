# SkillProof Design System

## 1. Visual Identity
SkillProof is a "Trust" platform. The design must feel academic yet futuristic, professional and authoritative.

### Color Palette
| Role | Color | Hex | Psychology |
| :--- | :--- | :--- | :--- |
| **Primary** | Deep Indigo | `#3F51B5` | Trust, Intelligence, Stability |
| **Secondary** | Electric Cyan | `#00E5FF` | Innovation, Technology, Energy |
| **Background** | Slate Dark | `#0F172A` | Focus, Professionalism (Dark Mode) |
| **Success** | Emerald Green | `#10B981` | Verification, Achievement |
| **Error** | Crimson Red | `#EF4444` | Failure, Alert |
| **Text** | Off-White | `#F8FAFC` | Readability, Clarity |

### Typography
- **Headings**: *Inter* or *Montserrat* (Bold, Geometric) $\rightarrow$ authoritative and modern.
- **Body**: *Roboto* or *Open Sans* (Regular) $\rightarrow$ highly legible for technical content.
- **Code**: *Fira Code* or *JetBrains Mono* (Monospaced) $\rightarrow$ essential for the editor.

## 2. Component Strategy
### The "Skill DNA" Visualization
Instead of a simple list, skills will be represented as:
- **Radar Charts**: To show balance between different areas (e.g., Logic vs. Efficiency).
- **Verification Badges**: "Proof-of-Skill" stamps that are only visible once a challenge is passed.

### The Editor Experience
- **Integrated IDE**: A clean, distraction-free code editor.
- **Live Status Bar**: Showing Time remaining, Memory usage, and "Run" status.
- **Split View**: Code on the left, Test Case results on the right.

## 3. User Experience (UX) Goals
- **Zero Friction**: A student should be able to start their first challenge within 3 clicks of landing.
- **Transparency**: When a test fails, the user should see exactly *why* (Actual vs. Expected) without compromising hidden test cases.
- **Pride of Proof**: The "Portfolio" page should feel like a trophy room, making students want to share their verified profiles on LinkedIn.
